# Чек-лист ручной проверки на реальном устройстве

Эмулятор не умеет мультитач (пинч) и идёт на software-GPU (~2–3 fps), поэтому перф- и жест-гейты
проверяются только на настоящем телефоне. Ставим release-APK (`app-release.apk`, подписан) и проходим
по списку. Для нагрузочных пунктов засеять журнал «Январь 2000» (28×~300): долгое нажатие на FAB «+»
в debug-сборке; в release нагрузочного сидера нет — используем реальный месяц или заранее
импортированный бэкап.

## Матрица (LOD/зум) — M4
- [ ] **Пинч-зум-аут** до «картины месяца»: два пальца свести → плавный уход в heatmap LOD2, весь месяц
      виден одним экраном, шапка-подрядчики читается (вертикальные shortName), колонка дат — числа.
- [ ] **Пинч-зум-ин** обратно к ячейкам с фото — точка под пальцами не «уезжает».
- [ ] **Double-tap** по ячейке: анимированный тумблер обзор ↔ 1:1, фокус в точке тапа.
- [ ] Кнопка **«Месяц» ↔ «1:1»** в шапке делает то же, что double-tap.
- [ ] **~60 fps** на живом журнале 28×~300 при пинче/скролле/fling (Developer Options → Profile GPU
      Rendering, полосы под зелёной линией; либо `adb shell dumpsys gfxinfo ru.papasheets`).
- [ ] Тап по heatmap-ячейке открывает **правильную** запись (дата/подрядчик совпадают со столбцом/строкой).

## Лайтбокс — M2
- [ ] Тап по фото в ячейке → полноэкранный лайтбокс, **пинч-зум и панорамирование** фото плавные.

## Камера и прерывание — M2, риск 5
- [ ] Снять фото из формы записи (системная камера) → возвращается, вписывается в ячейку.
- [ ] **Прерывание камеры**: пока открыта камера, свернуть/убить процесс (Developer Options → «Don't
      keep activities» ВКЛ) → вернуться; форма не теряет уже введённые поля, temp-uri не протух, фото
      импортируется либо чисто отменяется (без битой ссылки).

## Поворот и восстановление состояния
- [ ] **Поворот экрана** на матрице/форме/лайтбоксе — данные и открытые листы не пропадают.
- [ ] **«Don't keep activities» ВКЛ**: пройти форму записи с фото, свернуть-развернуть — состояние цело.

## Данные и удаление — M7/M8
- [ ] **Идемпотентный импорт**: импортировать один и тот же `.psbackup` дважды → второй раз «обновлено/
      пропущено», дубликатов журналов/записей/фото нет.
- [ ] **Каскадное удаление журнала** (long-press карточки → подтвердить): журнал, его записи и фото
      исчезают; свободное место возвращается (файлы фото удалены).
- [ ] EXIF-поворот фото корректен на снимках с камеры (проверить на Samsung, если есть).

## Экспорт — M6
- [ ] xlsx открывается в Excel и Google Sheets: merged-шапка, freeze B3, фото на местах; CSV без
      кракозябр (кириллица) в русском Excel.
- [ ] **Фото видны именно в Google Sheets НА ТЕЛЕФОНЕ** — у него мёртвая зона: мелкую (< ~52pt
      длинной стороной) и целиком вписанную в ячейку картинку он не рисует вовсе (правило и замеры —
      docs/evolution.md, «xlsx»). Обязательно после любой правки размеров фото, строк или колонок «Ф».

## Логи
- [ ] Меню ⋮ → «Отправить логи»: открывается системный выбор приложения, файл непустой — заголовок
      сессии (версия, Android, модель) и строки «экспорт начат/завершён» после пробного экспорта.
- [ ] Крэш-тест по желанию: убить процесс не обязательно, но после любого краша в логе должен быть
      стектрейс (uncaught handler), а приложение — штатно показать системный диалог, не зависнуть.

## M9 — проверено на реальном телефоне 2026-07-19

Обновление ставилось поверх сборки M8 (тот же ключ подписи), данные сохранялись.

- [x] **Миграции 1→5 на настоящих данных**: журнал, записи, фото, локации и виды работ
      пережили обновление. Это единственный способ проверить путь по-настоящему —
      androidTest гоняет его на выдуманных фикстурах.
- [x] Поля приходят из БД: в шапке Ф / Л / ВИД РАБОТ, редактор поля открывается и работает.
- [x] Вид «Список» с сортировкой по произвольному столбцу.
- [x] Длинный текст виден целиком в «Списке» — без обрезки.
- [x] Даты без года в матрице и списке.
- [x] Настройки таблицы доступны из меню «⋮» самого журнала.

Найдено на устройстве и не ловится тестами:

- [ ] **Колонки «Подрядчик» и «Л» в списке узкие** — имена рвутся посреди слова
      («Хамамщи/ки», «Плиточни/ки»).
- [ ] **Пустая полоса над шапкой списка.**
- [ ] **Автовысота раздувает строки матрицы**: одна длинная запись растягивает строку по всем
      колонкам, экран занимает пустота. Кандидат на потолок в 6–8 строк текста.

Осталось непроверенным (нужен живой жест или настоящий файл):

- [ ] Плавность пинч-зума и переход через порог LOD0↔LOD1.
- [ ] Задержка при открытии журнала (замер высот идёт синхронно в композиции).
- [ ] Предпросмотр печати xlsx в Excel: влезает ли текст, повторяется ли шапка.
- [ ] Импорт настоящего «Copy of Июнь.xlsx» — в эталоне вырезаны sharedStrings и фото,
      так что путь «фото из чужого файла попало в запись» вживую не гонялся.

## Логи и видимость фото в Sheets — проверено на реальном телефоне 2026-07-22/23

- [x] Файловый лог пишется с заголовком сессии; экспорт оставляет «экспорт начат/завершён»
      с числом записей и фото (снято с устройства через adb).
- [x] Правило видимости встроенных картинок в Sheets mobile снято A/B-файлами с одной переменной:
      видно ⟺ картинка вылезает за ячейку-якорь ИЛИ длинная сторона ≥ ~52pt; порог зажат лестницей
      размеров (42 — нет, 52 — да). Продакшн-геометрия 56pt подтверждена файлом-превью до правки кода.
- [ ] Кнопка «Отправить логи» руками на устройстве (шаринг-диалог) — ещё не прогонялась.
