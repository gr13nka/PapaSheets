# Чек-лист ручной проверки на реальном устройстве

Эмулятор не умеет мультитач (пинч) и идёт на software-GPU (~2–3 fps), поэтому перф- и жест-гейты
проверяются только на настоящем телефоне. Ставим release-APK (`app-release.apk`, подписан) и проходим
по списку. Для нагрузочных пунктов засеять журнал «Январь 2000» (28×~300): долгое нажатие на FAB «+»
в debug-сборке; в release нагрузочного сидера нет — используем реальный месяц или заранее
импортированный бэкап.

## Язык интерфейса
- [ ] **Новая установка** (`reinstall-phone.sh --clean`) следует системе: на русском языке системы —
      русский UI, на английском и любой неподдерживаемой локали — английский.
- [ ] **Обновление с 1.3** (поставить 1.3, затем новую сборку `reinstall-phone.sh` без `--clean`) на
      телефоне с НЕрусским языком системы остаётся на русском, в «Настройки → Язык» отмечен «Русский».
      Выбранное после этого «Как в системе» переживает перезапуск — разовый шаг русский не возвращает.
- [ ] «⚙ → Настройки → Язык»: English и Русский применяются сразу, переживают холодный запуск;
      «Как в системе» снова следует языку устройства.
- [ ] После переключения переведены даты, дни недели, матричная колонка даты, plurals, диалоги и
      сообщения ошибок; хранимые названия журналов/полей/подрядчиков и значения не переписываются.
- [ ] Круглая кнопка записи размером 56 dp содержит только «+», открывает новую запись и имеет
      TalkBack-подпись «Добавить запись» / “Add record”.
- [ ] **Раскладка после перехода на `AppCompatActivity`** не поехала: клавиатура в форме записи не
      закрывает поле ввода, верхняя панель не заезжает под статус-бар, FAB и полоска свёрнутой записи
      стоят над навигационной панелью, «Назад» из формы по-прежнему сохраняет запись.

## Форма записи — сохранение и сворачивание
- [ ] Новая запись: выбрать подрядчика, заполнить только «Локацию» (обязательный «Вид работ» пуст) →
      **свайп вниз** → запись появилась в матрице/списке, а внизу экрана осталась **полоска**
      «Запись свёрнута» с подписью вида «ГП · 1-01».
- [ ] То же **кнопкой «Назад»**, тапом по затемнению и **шевроном «⌄»** в шапке формы — результат тот же.
- [ ] Тап по полоске → форма развернулась, **набранное на месте**; дописать «Вид работ» → «Сохранить»
      → в журнале **одна** запись, не две (главная проверка сворачивания).
- [ ] Свернуть → развернуть → свернуть ещё раз → всё ещё **одна** запись.
- [ ] «×» на полоске → полоска ушла, запись осталась в журнале.
- [ ] Полоска **не закрывает** кнопку «+» и последнюю строку матрицы (обе видны над ней).
- [ ] Свернуть запись → нажать «+» → открылась ПУСТАЯ новая форма, полоска исчезла (не осталась
      с чужой подписью).
- [ ] Свернуть запись → долгий тап по ней в матрице → удалить → **полоска исчезла** (не разворачивается
      в вечную крутилку).
- [ ] Без выбранного подрядчика: ввести текст → свайп вниз → **лист возвращается**, «Группа»
      подсвечена, полоски нет. Кнопка «Не сохранять» закрывает и ничего не пишет.
- [ ] Открыть форму и сразу свайпнуть вниз → **не появилось ни пустой строки, ни полоски**.
- [ ] Правка существующей записи: изменить текст → свайп вниз → правка сохранена, **фото не
      потерялось и не задвоилось** (проверить оба слота).
- [ ] Дважды быстро нажать «Назад» на новой записи → в журнале **одна** запись, не две.
- [ ] Кнопка «Сохранить» по-прежнему требует обязательные поля (подсветка «Вида работ») и закрывает
      форму **совсем**, без полоски.

## Цвета значений
- [ ] В форме у каждого поля справа **кружок**: пустой контур, пока значение не введено (и не
      нажимается), цветной — когда значение покрашено.
- [ ] Ввести «Штукатурка» в «Вид работ» → кружок → выбрать цвет → в матрице **подколонка «ВИД РАБОТ»
      этой ячейки залилась**, текст поверх заливки читается.
- [ ] Завести вторую запись с тем же «Штукатурка» → она покрасилась **сама**, без повторного выбора.
- [ ] Начать вводить «Шту» → в подсказках автодополнения у варианта виден **его кружок цвета**.
- [ ] Отдалить зум до яруса, где текст уже не читается (LOD1) → **цветные полосы видны** и работают
      как картина; отдалить до «картины месяца» (LOD2) → блоки по-прежнему **по подрядчику**.
- [ ] Вкладка «Список» → та же заливка у ячеек тех же значений.
- [ ] Кружок → «Без цвета» → заливка ушла везде разом.
- [ ] Тёмная тема: заливка не съедает текст ни в матрице, ни в списке.

## Настройка группы

- [ ] Превью сверху следует за редактором **без задержки**: сдвиг слайдера ширины и правка
      «Подписи в шапке» меняют колонку в превью сразу, без ухода с экрана.
- [ ] Слайдер «Ширина» — **4 стопа**, над ним подпись меняется на имя пресета (Узкая/Средняя/
      Широкая/Очень широкая) по мере движения.
- [ ] Поле со значением ширины вне пресетов (например, 120dp из версии до пресетов) показывает
      **«Средняя»** при открытии редактора, и само это открытие ничего не пишет в БД — значение
      меняется только явным движением слайдера.
- [ ] «+ Добавить поле» → новое поле сразу **открывается в своём редакторе** (не остаётся в списке).
- [ ] Back — и системным жестом, и кнопкой в шапке — из редактора поля возвращает в **список
      полей**, а не сразу на «Настройки таблицы»; Back из списка уже уходит на «Настройки таблицы».
- [ ] **Drag-реордер** в списке полей работает и переставляет подколонки матрицы в том же порядке.
- [ ] Стереть «Название» или «Подпись в шапке» целиком → поле подсвечивается ошибкой, в БД
      остаётся прежнее непустое значение (не пустая строка).
- [ ] «В архив» на заполненном поле возвращает **в список**; в матрице подколонка пропадает,
      данные в старых записях не теряются.
- [ ] Изменения переживают уход с экрана: выйти в «Настройки таблицы» и обратно в журнал —
      новая ширина и подпись в шапке видны в матрице.

### Как снимать такие замеры (adb, без рук)

Способ проверен и повторяем; один A/B-файл с двумя колонками разной ширины решает вопрос за минуту:

```bash
ADB=~/.local/opt/android-sdk/platform-tools/adb
$ADB push проба.xlsx /sdcard/Download/проба.xlsx
$ADB shell "am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:///sdcard/Download/проба.xlsx"
ID=$($ADB shell "content query --uri content://media/external/file --projection _id \
     --where \"_display_name='проба.xlsx'\"" | grep -o '_id=[0-9]*' | cut -d= -f2 | tail -1)
$ADB shell "am force-stop com.google.android.apps.docs.editors.sheets"   # иначе покажет прошлый файл
$ADB shell "am start -a android.intent.action.VIEW --grant-read-uri-permission \
     -t application/vnd.openxmlformats-officedocument.spreadsheetml.sheet \
     -d content://media/external/file/$ID"
sleep 9 && $ADB exec-out screencap -p > снимок.png
```

- `file://`-интент не годится (`FileUriExposedException`) — только `content://` из MediaStore.
- Обе ветки A/B держать **в одном файле** разными колонками «Ф»: один снимок, никаких сомнений,
  что между запусками изменилось что-то ещё.
- Менять в пробе строго одну величину. Ошибка 2026-07-22 была именно в том, что меняли две.
