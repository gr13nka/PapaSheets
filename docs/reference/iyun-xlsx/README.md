# Эталон формата: распакованный «Copy of Июнь.xlsx»

XML-части реального файла журнала (без `xl/media/` — фото убраны, 25 JPEG ≈ 5.5 МБ).
Оригинал: `~/Downloads/Copy of Июнь.xlsx`. Это референс для `exportkit.XlsxWriter` (M6):
наш экспорт должен воспроизводить эту структуру.

Ключевые факты формата:
- Один лист «Лист2», dimension A1:CG1298; данные ~316 строк, дальше пустые.
- Freeze: `<pane xSplit="1" ySplit="2" topLeftCell="B3" state="frozen"/>` — колонка A (ДАТА) + 2 строки шапки.
- Шапка: строка 1 — имена подрядчиков, merge по 3 колонки группы (B1:D1, E1:G1, …), 28 групп;
  строка 2 — подписи Ф / Л / ВИД РАБОТ в каждой группе.
- Ширины колонок: Ф ≈ 5.8, Л ≈ 7.8, ВИД РАБОТ ≈ 50.8 (у Г.П. шире: C=7.8, D=68.8).
- Колонка A: даты (несколько строк на дату, строка = одна запись).
- Фото: `xl/drawings/drawing1.xml`, `<xdr:oneCellAnchor>`, привязка к Ф-ячейкам,
  размеры в EMU (px × 9525). Портретные 576×1024 … 1536×2048.
- Наш экспорт: строки писать как `t="inlineStr"` (эталон использует sharedStrings —
  различие допустимо, Excel/Sheets едят оба варианта).
